# Еталонні випадки калькулятора

Спільні для Python-рушія (`backend/apps/calc/engine`) і порту на TypeScript (`web/src/calc`).
Обидві реалізації проганяють кожен файл із `cases/` з налаштуваннями `settings.json`
і мають отримати ті самі числа до копійки. Розбіжність валить CI.

Формат випадку:

- `input` — ввід калькулятора, як у POST /api/v1/calc/estimate, але з плиткою, описаною повністю;
- `expected` — очікуваний результат: площі, рядки, сума, вага, коди попереджень;
- `expected_error` — замість `expected`, якщо ввід некоректний: `code` і `field`.

Десяткові числа записуються рядками з фіксованою кількістю знаків, гроші — цілими копійками.
Нові випадки додаються після звірки із замовником.
